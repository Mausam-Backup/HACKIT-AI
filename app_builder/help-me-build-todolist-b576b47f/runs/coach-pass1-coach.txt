### 🧠 Key Design Decisions

1. **No migrations** — `CREATE TABLE IF NOT EXISTS` on startup keeps it simple
2. **Re-fetch on mutation** — Frontend re-fetches the full list after add/toggle/delete (simple, correct)
3. **Single table** — `todos(id, title, completed, created_at)` — no join complexity
4. **Validation on both sides** — Backend validates title length/type; frontend trims and disables empty submits
5. **Vite proxy** — Already configured to proxy `/api` → `localhost:3001` in dev mode
