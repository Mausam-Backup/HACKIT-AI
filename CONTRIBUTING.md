# Contributing to HACKIT-AI

First off, thank you for considering contributing to HACKIT-AI! It's people like you that make this multi-agent orchestration engine such a powerful tool for the community.

## How Can I Contribute?

### 1. Reporting Bugs
If you find a bug, please create an issue on GitHub with:
- A descriptive title
- Steps to reproduce
- Expected vs. actual behavior
- Your environment details (OS, Node version, Python version)

### 2. Suggesting Enhancements
Have an idea for a new AI workflow or an improvement to the App Builder CLI? Open an issue and use the "Feature Request" label. 

### 3. Submitting Pull Requests
We welcome PRs for both bug fixes and new features!
1. **Fork** the repository.
2. **Clone** your fork locally.
3. **Branch** off of `main` (e.g., `git checkout -b feature/amazing-new-agent`).
4. **Develop** your changes. Please ensure you test them against the existing architecture.
5. **Commit** your changes with clear, descriptive commit messages.
6. **Push** your branch to your fork.
7. **Open a Pull Request** against the main repository.

## Development Setup

See the [README.md](README.md) for detailed setup instructions for both the FastAPI backend and Next.js frontend. 

When contributing to the AI components, please ensure your changes are compatible with the FastMCP context server architecture and OpenRouter integration.

## Code of Conduct

By participating in this project, you agree to maintain a welcoming, inclusive, and harassment-free environment for everyone. Please be respectful in all interactions.

Thank you for helping us build the ultimate hackathon winning kit!
